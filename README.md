
# heritage-thermal-monitoring - Платформа мониторинга состояния объектов культурного наследия с тепловым контуром
## Общая цель системы
### Платформа, которая:
### 1. Хранит и отображает данные об объектах культурного наследия Новочеркасска.
### 2. Получает (или эмулирует) данные о тепловом режиме этих объектов.
### 3. Анализирует влияние температурно-влажностного режима на состояние зданий.
### 4. Выявляет риски (промерзание, конденсат, перепады и т.д.) и показывает их на карте/в паспорте объекта.
|              |Часть А — «Цифровой реестр и мониторинг состояния объектов наследия»|Часть Б — «Тепловой контур и анализ рисков»|
| --- | :--- | :---: |
|Основной фокус|"Объекты культурного наследия, их паспорта, визуализация, поиск и оценка состояния"|"Сбор/обработка тепловых данных, алгоритмы выявления аномалий и расчёта рисков"|
|Кто чем занимается|"Всё, что связано с архитектурой, историей, визуализацией и «охранной» частью"|"Всё, что связано с датчиками, температурой, влажностью, расчётами и рекомендациями"|
|Ключевые модули|• Реестр объектов• Паспорт объекта• Поиск / фильтрация / сортировка• Карта объектов• Модуль оценки общего состояния|• Адаптер получения тепловых данных (API / эмуляция)• Хранение временных рядов• Алгоритмы поиска аномалий• Расчёт рисков• Рекомендации по режиму|
|Общее |,"Общая база данных, Git-репозиторий, интерфейс обмена данными, интеграция модулей"|
